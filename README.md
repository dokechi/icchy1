# イッチー

「知らないまま、払いすぎない。」を合言葉に、次の4テーマへ迷わず進むための静的サイトです。

1. 1株で優待
2. スマホ代を下げる
3. 保険を考える
4. けっこうお得

## 設計の基準

- トップはホームページではなく、4択ランチャーとして扱う
- 通常文字サイズでは、トップを1画面に収める
- 見た瞬間に構図と次の操作が分かるようにする
- トップへニュース、長文、プロフィール、画像を追加しない
- 詳細画面は読みやすさを優先し、必要な縦スクロールを許す
- 文字拡大や極小画面では、内容を隠さず縦スクロールを許す
- 派手さより、文字、線、余白、押した反応の精度を優先する

## ファイル構成

```text
.
├─ index.html                 サイト本体
├─ assets/comic/              詳細画面で遅延表示するWebP画像
├─ docs/baseline/             改善前のV59説明・検証記録
├─ CHANGELOG.md               今回の変更記録
└─ TEST_REPORT.md             現在の検証結果
```

## 今回の改善

- HTML内に埋め込まれていた14枚のWebP画像を外部ファイル化
- `index.html`を約3.92MBから約145KBへ軽量化
- 画像を遅延読み込みし、縦横サイズを指定して表示のずれを抑制
- ページごとのタイトルと説明文をハッシュ遷移に合わせて更新
- Open Graph、X、JSON-LDの基本情報を追加
- キーボード利用者向けの「本文へ移動」を追加
- JavaScript無効時の案内を追加

トップの見出し、4択の文言、順番、無スクロール方針は変更していません。
