# イッチー

「知らないまま、払いすぎない。」を合言葉に、固定費を次の2テーマから見直す静的サイトです。

1. 楽天モバイルを他社と条件まで比較する
2. 民間保険の前に、公的保障・勤務先保障・貯金を確認する

## 現在の設計

見た目は2000年代の価格比較サイトや自治体サイトに寄せていますが、情報設計とスマホ操作は現代基準です。

- トップは「スマホ」「保険」の2択ランチャー
- 通常文字サイズでは、一般的なスマホでトップを1画面に収める
- 楽天ページは既存の「通信量 × 割引条件」の切替機能と料金データを維持
- 楽天が最安ではない条件も隠さない
- 保険ページは既存の「国・会社・貯金 → 不足分だけ民間保険」という判断順を維持
- 保険商品や必要保障額をサイト側で決めない
- 保険相談は「営業だと理解したうえで使う」ページを経由する
- 青リンク、赤い重要数字、黄色の注意、水色の説明、四角い枠を使用する
- 意図的な整列崩し、点滅、虹色、不要な3Dグラフは使わない

## 実装方法

`mobile.html` と `app.html` の本文・計算処理・料金データは変更せず、ランチャーから iframe へ読み込んだ後に、平成比較サイト風のCSSと補助JSを注入します。

これにより、見た目と情報の優先順位だけを変え、既存の比較機能・制度内容・公式リンク・広告リンクを壊さない構成にしています。

## 方針

ダサさそのものを目的にしません。

> 古く見える色・枠・リンクを使いながら、情報の優先順位、整列、操作性は厳密にする。

楽天モバイルと保険相談には広告リンクが含まれます。PR表示を行い、申込前に公式条件を確認する導線を残します。
